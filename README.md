# 🐾 Churu Paw Shop

고양이를 위한 츄르 판매 및 재고 관리 웹 프로젝트입니다.

## 📌 프로젝트 소개

Churu Paw Shop은 관리자와 회원의 역할을 구분하여 츄르 상품을 관리하고 구매할 수 있는 웹 프로젝트입니다.

현재 HTML, CSS, Bootstrap을 활용하여 화면을 구현하였으며, 추후 Java, Oracle DB를 연동하여 실제 동작하는 웹 서비스로 확장할 예정입니다.

---
