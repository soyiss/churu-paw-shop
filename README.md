# 🐾 Churu Paw Shop

고양이를 위한 츄르 판매 및 재고 관리 웹 프로젝트입니다.

## 프로젝트 소개

Churu Paw Shop은 관리자와 사용자를 구분하여 관리할 수 있는 웹 쇼핑몰 프로젝트입니다.

### 관리자 기능

* 로그인
* 상품 등록
* 상품 수정
* 재고 관리
* 판매 현황 조회

### 사용자 기능

* 회원가입
* 로그인
* 상품 조회
* 상품 구매
* 구매 내역 조회

## 기술 스택

* HTML
* CSS
* JavaScript
* Java
* JSP / Servlet
* Oracle DB

## 프로젝트 화면

### 메인 페이지

* 로그인
* 회원가입
* 사용자 및 관리자 권한 분리
